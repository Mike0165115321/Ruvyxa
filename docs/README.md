# Ruvyxa documentation

## Learn by building

Treat chapters 1–7 as one guided build: create a small app, add routes and server behavior, then
configure it safely. Chapters 8–10 extend that app; chapters 13–15 prepare it for production. Every
chapter begins with a goal and a starting point, and ends with a link to the next useful lesson. Run
the stated checkpoint before moving on.

This documentation set is generated from the current source tree, package manifests, CLI
declarations, templates, and tests. It deliberately does not use pre-existing documentation as a
technical source.

| Language | Start here                            | Complete index                |

Both editions have the same file names, chapter order, examples, diagrams, and cross-links. API
identifiers, package names, configuration keys, and terminal commands remain in English because they
are code contracts. Choose one language tree for a continuous tutorial; use the other only as a
translation reference.
